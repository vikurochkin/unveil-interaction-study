# UNVEIL® interaction study

A responsive, two-route recreation of the public [UNVEIL®](https://unveil.fr) portfolio experience.

- `/` — animated 3D project tunnel with wheel, drag, touch, keyboard, Index, and Contact interactions.
- `/nto-stratus` — recreated NTO / Stratus project page with the original public media, custom controls, responsive gallery, and a shared-card route transition.

This repository is an independent technical and interaction study. UNVEIL® and the project imagery belong to their respective owners.

## Development

```bash
pnpm install
pnpm dev
```

## Verification

```bash
pnpm test -- --run
pnpm build
```
